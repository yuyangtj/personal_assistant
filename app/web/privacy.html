Privacy policy

This is a personal assistant run by one person, Yang Yu, for their own use. It is not offered to anyone else, and only its owner can sign in.

Google data

With the owner's permission, the assistant reads the owner's own Google Drive, read-only (the drive.readonly scope): it lists a folder or reads a file's text when the owner asks about a Drive link. It never creates, changes, deletes or shares anything in Drive.

A file's text is used only to answer the request it was read for. To do that it is sent to the AI model provider that writes the assistant's reply. It is not sold, not shared with anyone else, not used for advertising, and not used to train models by this service. Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
